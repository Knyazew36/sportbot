# Спортбот — бизнес-ТЗ приложения

Версия 1.0 от 13.10.2026. Описывает Mini App спортбота: что видит и делает пользователь на каждом экране. Правила предметной области (ротация, засчитывание, заминка, серия, статистика, модерация, видимость) здесь не повторяются, а даются ссылкой на разделы `business-tz.md`. Если правило в этом документе расходится с `business-tz.md`, верен `business-tz.md`.

Стек, API и макеты не описываются: стек задан шаблоном `apps/frontend`, API — в техническом ТЗ, внешний вид — отдельным дизайн-заданием.

## 1. Назначение

Приложение даёт тем же пользователям бота удобный интерфейс для всего, что кнопками в чате делать неудобно: сборку программ, справочник, ввод подходов, статистику с графиками, администрирование. Плюс то, что в чате невозможно в принципе: таймеры отдыха и удержания.

Бот остаётся: он задаёт вопросы, напоминает, присылает сводку и ведёт в приложение.

## 2. Рамки

| Параметр | Решение |
|---|---|
| Форма | Mini App внутри Telegram и внутри MAX. Один код фронта, один API на обе платформы |
| Вход | Только из бота. Отдельного сайта, логина и пароля нет |
| Паритет с ботом | Всё, что умеет бот (часть I `business-tz.md`), умеет и приложение |
| Только в приложении | Таймер отдыха, таймер удержания растяжки, пошаговая заминка, интерактивные графики, календарь истории, список «Мои» со статусами заявок, админ-раздел с формами |
| Сеть | Только онлайн. Офлайн-режима и очереди нет |
| Устройства | Телефон. На компьютере (Telegram Desktop и т. п.) та же мобильная раскладка, ограниченная по ширине |
| Аудитория, язык, ИИ, оплата | Как у бота (`business-tz.md`, раздел 2) |

## 3. Роли

- **Пользователь** — любой, кто запускал бота.
- **Администратор** — тот же, что в боте (`business-tz.md`, раздел 3). Видит дополнительный раздел «Админ».
- **Заблокированный** — приложение не открывает ничего, кроме экрана «Доступ закрыт».

## 4. Бот и приложение

### 4.1. Общее состояние

Бот и приложение работают с одними и теми же данными. Любое действие в одном месте сразу видно в другом.

- Тренировку, начатую в боте, можно продолжить в приложении, и наоборот. Введённые подходы видны в обоих местах.
- Если одно и то же изменили одновременно в двух местах, сохраняется последнее изменение.
- При возвращении в приложение после паузы данные текущего экрана обновляются, чтобы не показывать устаревшее.

### 4.2. Что остаётся только за ботом

- Утренний и вечерний вопросы, напоминания, повторные вопросы, предложение переноса и паузы (`business-tz.md`, раздел 8).
- Вопрос о весе тела по расписанию (раздел 12).
- Воскресная личная сводка (раздел 9).
- Уведомления: исход модерации, «друг обновил программу», заявки и жалобы администратору.

Ответить на эти вопросы можно и в приложении: состояние дня видно и меняется на экране «Сегодня» (раздел 7).

### 4.3. Что только в приложении

Таймеры (8.3, 9) в боте не появляются, бот про них ничего не знает и ничего не присылает.

## 5. Вход в приложение

### 5.1. Точки входа

1. Постоянная кнопка меню бота «Открыть приложение» (в Telegram — кнопка меню чата, в MAX — её аналог).
2. Команда `/app` — бот отвечает кнопкой «Открыть приложение».
3. Кнопки «Открыть в приложении» в сообщениях бота. Каждая ведёт сразу на нужный экран:

| Сообщение бота | Экран приложения |
|---|---|
| Утренний вопрос, комплекс дня | Сегодня |
| Завершение тренировки | Заминка этой тренировки |
| Приглашение в друзья (после принятия) | Профиль друга |
| «Друг обновил программу» | Программа-копия с предложением обновить |
| Исход модерации | Справочник → Мои → эта запись |
| Заявка на модерацию (админу) | Админ → карточка заявки |
| Жалоба (админу) | Админ → карточка жалобы |

Кнопки бота при этом остаются: всё можно сделать и в чате.

### 5.2. Первое открытие

- Приложение узнаёт пользователя по аккаунту мессенджера, из которого открыто. Аккаунт тот же, что в боте, в том числе с привязанным вторым мессенджером (`business-tz.md`, 22.4).
- Если первый запуск (3 шага, `business-tz.md`, раздел 13) не закончен, приложение открывает его с того же шага. Пройти его можно и в боте, и в приложении — продолжается с того места, где остановились.
- Если мессенджер не разрешает боту писать пользователю, приложение показывает запрос разрешения (в Telegram — штатный запрос на сообщения от бота). При отказе на экране «Сегодня» висит баннер «Бот не сможет задавать вопросы и напоминать — разрешить», по нажатию запрос повторяется.

### 5.3. Ошибки входа

| Ситуация | Что видит пользователь |
|---|---|
| Приложение открыто не из мессенджера | «Открой приложение из бота» и ссылка на бота |
| Пользователь заблокирован | «Доступ закрыт», без подробностей |
| Нет сети или сервер недоступен | «Нет связи» и кнопка «Повторить» |

## 6. Навигация

Нижнее меню из пяти разделов, у администратора шестой:

1. **Сегодня** — день и текущая тренировка.
2. **Программы** — программы, комплексы, шаблоны.
3. **Справочник** — упражнения, растяжки, свои записи.
4. **Статистика** — показатели, графики, календарь.
5. **Профиль** — настройки, друзья, пауза, ограничения, вес тела, мессенджеры, удаление данных.
6. **Админ** — только у администратора.

Во время тренировки и заминки нижнее меню скрыто, выход — кнопкой «Назад» мессенджера с подтверждением «Тренировка останется открытой». Кнопка «Назад» мессенджера везде работает как шаг назад внутри приложения.

## 7. Сегодня

Главный экран. Показывает одно из состояний дня:

| Состояние | Что на экране |
|---|---|
| Первый запуск не закончен | Продолжение настройки |
| Нет активной программы | «Программы нет» и кнопки «Взять шаблон» / «Собрать свою» |
| Тренировочный день, тренировки ещё не было | Комплекс по ротации (`business-tz.md`, 6.3), кнопки «Начать», «Другой комплекс», «Сегодня не буду» |
| Нетренировочный день | «Сегодня отдых», комплекс по ротации свёрнут, кнопка «Всё равно потренироваться» (внеплановая тренировка, 7.2) |
| Тренировка идёт | Название комплекса, «сделано N из M», кнопка «Продолжить» |
| Тренировка завершена | «Тренировка засчитана ✅», серия, кнопка «Заминка» |
| День отмечен пропуском | «Пропуск», кнопка «Исправить» по правилам исправления (8.3 и 25.9) |
| Пауза | «На паузе до …» или «до отмены», кнопка «Снять паузу». Если срок истёк — вопрос «Возвращаемся?» (8.5) |

Дополнительно на экране:

- Текущая серия.
- Баннер про разрешение писать (5.2), если нужен.
- Карточка комплекса показывает упражнения с планом подходов и повторов. Упражнения, нагружающие зону с активным ограничением, помечены ⚠️ с подписью «нагружает плечо — заменить?» (`business-tz.md`, раздел 11).

«Сегодня не буду» и вечерний ответ работают как кнопки опроса бота: ставят пропуск и предлагают перенос по правилам 8.4. Ответ, данный в приложении, бот больше не спрашивает.

## 8. Тренировка

Режим учёта один — детальный: записываются подходы, повторы и веса (`business-tz.md`, 7.1).

### 8.1. Экран тренировки

- Сверху: название комплекса, прогресс «упражнение 2 из 6», кнопка «Завершить».
- Список упражнений с отметками «сделано / текущее / впереди». Можно перейти к любому упражнению, порядок не обязателен.
- Карточка текущего упражнения:
  - название, ⚠️ при ограничении;
  - кнопки «Техника» (текст, картинка, ссылка на видео) и «Заменить»;
  - план: «3 × 8–12»;
  - прошлый результат по этому упражнению: «прошлый раз 60 × 8, 8, 7». Если истории нет — «первый раз»;
  - строки подходов.

### 8.2. Ввод подхода

- Поля «вес» и «повторы» открываются **пустыми**. Подсказкой рядом — значение того же подхода в прошлый раз. Рекомендаций по весу нет.
- Вес в килограммах, допустимые значения — как при вводе в боте. Для упражнений с собственным весом поле веса необязательное.
- «Готово» сохраняет подход. Сохранённый подход можно исправить или удалить, пока тренировка не завершена.
- Подходов можно сделать больше или меньше плана.
- «Упражнение сделано» переводит к следующему несделанному.

### 8.3. Таймер отдыха

- После «Готово» по подходу таймер отдыха стартует сам. Длительность — из настроек пользователя (13.2).
- На экране: обратный отсчёт и кнопки «+30 с» и «Пропустить».
- По окончании — звук и вибрация, если приложение открыто.
- Автостарт выключается в настройках. Тогда таймер запускается кнопкой «Отдых».
- Таймер считается от момента старта: свёрнутое приложение, погасший экран или переход на другой экран отсчёт не сбивают. При возвращении видно актуальное время или «Отдых закончился N с назад». Поведение в свёрнутом виде уточняет техническое ТЗ.

### 8.4. Замена упражнения

По сценарию `business-tz.md`, 7.4: список аналогов с теми же основными мышцами (с ограничением — без упражнений на ту же зону), затем выбор «только сегодня» или «заменить в комплексе». Прошлый результат после замены показывается по аналогу.

### 8.5. Другой комплекс

До начала тренировки можно выбрать любой комплекс активной программы вместо предложенного по ротации.

### 8.6. Завершение

- «Завершить» — подтверждение со сводкой «сделано N из M упражнений». Засчитывание по правилам 7.3: хотя бы одно упражнение.
- Если тренировка не завершена до вечера, бот спрашивает «Закончил?» (7.3) — ответить можно и в приложении, кнопкой «Завершить».
- После завершения — экран итога: время тренировки, подходы, серия, кнопка «Заминка».

## 9. Заминка

Состав и порядок растяжек — строго по `business-tz.md`, 7.5. Набор не меняется при повторном открытии.

### 9.1. Пошаговый режим (по умолчанию)

- Обзор: суммарное время, список основного блока и блока «если есть время», кнопка «Начать».
- Одна растяжка на экране: название, картинка, текст «как делать», какие мышцы тянет.
- Таймер удержания по времени растяжки. Для растяжек «на каждую сторону» — два круга подряд с подсказкой «Другая сторона».
- По окончании — звук и вибрация и автопереход к следующей растяжке.
- Кнопки «Пауза», «Пропустить», «Назад к предыдущей».
- После основного блока — вопрос «Есть время ещё на N мин?»: блок «если есть время» или выход.

### 9.2. Список

Из любого места заминки можно открыть весь список и перейти к любой растяжке.

Заминка доступна с экрана итога тренировки и из «Сегодня», пока день не закончился. Прохождение заминки ничего не записывает в статистику.

## 10. Программы

По `business-tz.md`, раздел 6.

### 10.1. Список программ

- Все программы пользователя, активная отмечена. Переключение активной — одним действием.
- Программы-копии от друга помечены «от {имя}».
- Кнопки «Новая программа»: «Из шаблона» или «С нуля».

### 10.2. Шаблоны

Список шаблонов с описанием и составом комплексов. «Взять» создаёт копию в программах пользователя.

### 10.3. Редактор программы

- Название программы.
- Комплексы в порядке ротации: добавить, переименовать, удалить, поменять порядок перетаскиванием. Видно, какой комплекс следующий по ротации.
- Внутри комплекса — упражнения: добавить, удалить, поменять порядок, задать подходы и диапазон повторов (например, 3 × 8–12).
- Добавление упражнения: поиск по названию и фильтр по группе мышц, как в справочнике. Личные черновики показываются с пометкой «не проверено».
- Удаление комплекса и программы — с подтверждением. История тренировок при этом сохраняется.

### 10.4. Копия от друга

- Отметка «Друг обновил программу» с кнопкой «Обновить у себя».
- Перед обновлением — предупреждение, что собственные правки в копии пропадут, история тренировок и весов сохранится (`business-tz.md`, 10.1).

## 11. Справочник

### 11.1. Поиск

- Вкладки «Упражнения» и «Растяжки».
- Строка поиска по названию и фильтры: группа мышц, инвентарь.
- В выдаче — общий справочник и собственные черновики (с пометкой «не проверено»).

### 11.2. Карточка упражнения

Название, картинка, техника (ключевые пункты и типичные ошибки), ссылка на видео, инвентарь, основные и вспомогательные мышцы, нагружаемые суставы (`business-tz.md`, 5.2). Действия: «Добавить в комплекс», «Ошибка в описании» (жалоба, 5.7).

### 11.3. Карточка растяжки

Название, картинка, «как делать», мышцы, время удержания, «на каждую сторону». Действия: «Попробовать» (таймер удержания, как в 9.1), «Ошибка в описании».

### 11.4. Своё упражнение или растяжка

Мастер по `business-tz.md`, 5.5:

1. Название. По мере ввода — подсказка «возможно, ты искал…» с похожими записями справочника.
2. Мышцы — обязательно. Для растяжки — время удержания и «на каждую сторону».
3. По желанию: текст техники, ссылка на видео.

Картинку пользователь не загружает: её добавляет администратор при модерации.

Лимит 5 заявок в сутки. При исчерпании мастер не открывается, показывается «Лимит на сегодня исчерпан, завтра можно снова».

### 11.5. Вкладка «Мои»

Все записи пользователя со статусом:

| Статус | Что видно |
|---|---|
| На проверке | Черновик, можно ставить в комплексы |
| Одобрено | Ссылка на запись в общем справочнике |
| Одобрено с правками | То же |
| Дубль | Ссылка на существующую запись, которая заменила черновик |
| Отклонено | Причина. Запись остаётся личным черновиком |

## 12. Статистика

Показатели и правила расчёта — строго по `business-tz.md`, раздел 9. Новых метрик нет. Все графики интерактивные: касание точки показывает значение и дату, период переключается.

### 12.1. Сводка

- Посещаемость за неделю и за месяц.
- Серия: текущая и рекордная.

### 12.2. Графики

| График | Что показывает |
|---|---|
| Прогресс весов | По выбранному упражнению: лучший вес по тренировкам |
| Вес тела | Записи веса тела по датам |
| Посещаемость | Процент по неделям |
| Нагрузка по мышцам | Подходы за неделю на группу мышц, столбцами. Мышцы с нулём за 2 недели отмечены «забыто» |

### 12.3. Календарь

- Месяц, по дням: тренировка / пропуск / пауза / перенос / ожидает ответа / отдых.
- Касание дня — детали: комплекс, упражнения, подходы и веса.
- Исправление отметки — в пределах правил `business-tz.md`, 8.3 и 25.9.

## 13. Профиль

### 13.1. Расписание

- Тренировочные дни недели.
- Время утреннего и вечернего вопроса.
- Часовой пояс: выбор города или ввод текущего времени, как в боте. По умолчанию Москва, автоопределения по устройству нет.

### 13.2. Тренировка

- Длительность отдыха между подходами — задаёт пользователь.
- Автостарт таймера отдыха — вкл/выкл.
- Звук и вибрация по окончании таймеров — вкл/выкл.

### 13.3. Пауза

Поставить «до даты» или «до отмены», снять досрочно (`business-tz.md`, 8.5).

### 13.4. Ограничения по суставам

Список активных ограничений, добавление (зона и срок «до даты» / «до отмены»), снятие. При первом включении — дисклеймер «не заменяет врача» (раздел 11).

### 13.5. Вес тела

Ввод веса за сегодня, история с графиком (ссылка на 12.2), частота вопроса от бота: выкл / варианты из бота (раздел 12).

### 13.6. Друзья

- «Пригласить» открывает системное «Поделиться» со ссылкой-приглашением на бота (`business-tz.md`, 10.1).
- Список друзей: имя, серия, тренировался ли сегодня.
- Профиль друга: его статистика с графиками и календарём — строго по таблице видимости `business-tz.md`, раздел 15 (без веса тела и ограничений), статус паузы, его программы с кнопкой «Скопировать себе».
- «Удалить из друзей» — с подтверждением, второй стороне уведомление не приходит.

### 13.7. Мессенджеры

- Какие мессенджеры привязаны к аккаунту.

## 14. Админ

Виден только администратору. Мобильная раскладка, таблицы — списками карточек.

### 14.1. Справочник

- Список упражнений и растяжек с поиском и фильтрами, включая «без картинки» и «без мышц».
- Создание и правка формой: все поля `business-tz.md`, 5.2 и 5.3, загрузка картинки, выбор мышц (основные и вспомогательные) и суставов.

### 14.2. Шаблоны

Тот же редактор, что для программ (10.3), но для шаблонов, плюс описание шаблона.

### 14.3. Модерация

- Очередь заявок: автор, запись, похожие записи справочника.
- Исходы: одобрить, одобрить с правками (открывает форму 14.1 с картинкой), дубль (выбор существующей записи), отклонить. Для каждого — короткая причина для автора (`business-tz.md`, 5.6).

### 14.4. Жалобы

Список жалоб с текстом и ссылкой на запись. Действия: открыть запись на правку, закрыть жалобу.

### 14.5. Пользователи

Список пользователей с поиском, заблокировать и разблокировать (`business-tz.md`, 30.3).

### 14.6. Импорт

Загрузка файла импорта, отчёт: сколько создано, сколько обновлено, ошибки по строкам (`business-tz.md`, 30.2).

## 15. Общие требования к экранам

- У каждого списка и экрана данных есть состояния «загрузка», «пусто» (с подсказкой, что сделать) и «ошибка» (с кнопкой «Повторить»).
- Любое удаление и необратимое действие — с подтверждением.
- Управление одной рукой в зале: основные кнопки тренировки и таймера в нижней половине экрана, крупные цели нажатия.
- Тема (светлая / тёмная) следует за мессенджером.
- Тексты и формулировки — как в боте (`business-tz.md`, раздел 17), чтобы бот и приложение говорили одинаково.

## 16. Отличия Telegram и MAX

Различия платформ закрывает фронт, для пользователя приложение одинаковое.

| Что | Требование |
|---|---|
| Вход | Пользователь определяется по данным запуска Mini App каждой платформы |
| Кнопка «Назад» | Системная кнопка мессенджера, где она есть |
| Тема | Светлая / тёмная — по мессенджеру |
| Вибрация | Через возможности платформы. Где их нет — без вибрации |
| Разрешение писать | Где есть штатный запрос — через него. Где нет — подсказка написать боту `/start` |
| «Поделиться» | Штатный диалог платформы, иначе — копирование ссылки |
