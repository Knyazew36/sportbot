# Контент справочника: упражнения, растяжки, программы

Справочник живёт в базе прода: его правят админ, модерация и жалобы с правками. Поэтому прод — источник правды, а этот каталог — инструменты, чтобы безопасно выкачать справочник, поправить или дополнить его и залить обратно, ничего не затерев.

## Файлы

| Файл | Что это |
|---|---|
| `catalog.json` | Полный справочник для чистой установки (`content.sh`). После каждой заливки на прод в него вливается то же самое (`content:merge`), чтобы он совпадал с продом. |
| `patches/<дата>-<что>.json` | Изменения для прода в формате импорта: новые упражнения, растяжки, теги, программы, снятие программ с витрины. Один патч — одна задача. |
| `guides.json` | Техника существующих записей: описание, шаги, ошибки, фото финиша. Привязана к `id` и `updatedAt` записи на проде. |
| `guides-review.md` | Было → стало по каждой записи `guides.json` — для ревью глазами. |
| `sources/*.json` | Снимки внешних источников техники (free-exercise-db, wger). Факты для текстов берём только отсюда. |
| `prod/` | Локальные снимки прода (`content:export`). В git не попадают. |

## Цикл: выкачать → поправить → проверить → залить

### 1. Выкачать прод

```bash
ssh root@185.200.176.192 'cd /var/www/sportbot/apps/server && yarn -s content:export /tmp/catalog-export.json'
scp root@185.200.176.192:/tmp/catalog-export.json apps/server/prisma/content/prod/catalog-export.json
```

Только чтение. В снимке:
- упражнения и растяжки справочника (`status = CATALOG`) с `id`, `code`, `updatedAt` и текущей техникой;
- группы тегов, теги и шаблоны программ — в формате импорта, их можно копировать в патч как есть.

### 2. Поправить

**Новое или изменённое по `code`** (упражнения, растяжки, теги, программы) — патч `patches/<дата>-<что>.json`:

```json
{
  "exercises": [{ "code": "goblet-squat", "name": "…", "technique": "…", "steps": [], "mistakes": [], "image": "https://…/0.jpg", "imageEnd": "https://…/1.jpg", "equipment": "DUMBBELL", "primary": ["quads"], "secondary": [], "joints": ["knee"] }],
  "programTagGroups": [{ "code": "goal", "name": "Цель", "position": 2 }],
  "programTags": [{ "code": "strength", "name": "Сила", "group": "goal" }],
  "programs": [
    { "code": "strength-5x5", "name": "Сила 5×5", "tags": ["gym"], "description": "…", "complexes": [ … ] },
    { "code": "fullbody-3", "published": false }
  ]
}
```

Правила импорта (`src/admin/import.service.ts`):
- запись ищется по `code`: есть — обновляется, нет — создаётся. Удаления нет;
- **в патч клади только то, что меняешь.** Упражнение из патча перезапишет на проде название, технику и мышцы — правки людей в этих полях пропадут;
- у упражнения поля `steps`, `mistakes` и `imageEnd` необязательны: если их нет, существующие на проде не трогаются. А `technique` (у растяжки `howTo`) без поля станет пустым — для существующей записи его нужно передать;
- упражнение **без** `primary` — частичная запись существующего упражнения: меняются только переданные поля (`measure`, `equipment`, `videoUrl`, `technique`, `steps`, `mistakes`), название, мышцы и картинки не трогаются. Так переводят упражнение на время: `{ "code": "plank", "measure": "TIME" }`;
- `measure`: `REPS` (подходы × повторы × вес, по умолчанию), `TIME` (удержания вроде планки, вводятся секундами, диапазон «30–60 с») или `MINUTES` (кардио, вводятся минутами одним числом). У TIME и MINUTES в `repsMin`/`repsMax` программы — **секунды**; у кардио обе границы равны: 20 минут дорожки — `{ "sets": 1, "repsMin": 1200, "repsMax": 1200 }`;
- блока `cardio` у комплекса больше нет: кардио — упражнение на время отдельной строкой комплекса. Файл с `cardio` импорт не примет;
- программа с `complexes` заменяет состав шаблона целиком;
- программа **без** `complexes` — частичная запись: меняет только переданные поля (`published`, `tags`, `description`, `name`) у уже существующего шаблона. Так шаблон снимают с витрины (`"published": false`), не затирая его состав;
- шаблоны отделены от программ пользователей: скрытие шаблона ничего не меняет у тех, кто его уже взял;
- коды упражнений в программах — из справочника прода (снимок) или из этого же патча.

**Техника существующих записей** — `guides.json`, по `id` записи на проде:
- вручную или скриптом `content:enrich` (Claude Batch API, нужен `ANTHROPIC_API_KEY`):
  ```bash
  yarn content:enrich prisma/content/prod/catalog-export.json --limit 10   # проба
  yarn content:enrich prisma/content/prod/catalog-export.json               # всё
  ```
  на выходе `enrich-out/guides.json` и `enrich-out/review.md`;
- `updatedAt` в каждой записи берётся из снимка: если запись поправили на проде после выкачки, при заливке она пропускается.

**Тексты** (и в патчах, и в технике):
- факты — только из текущего текста записи и снимка источника (`sources/`), ничего не выдумываем; при расхождении верим текущему тексту;
- на «ты», коротко, для новичка, без медицинских обещаний;
- «очередь», а не «ротация»;
- ошибка пишется сразу с исправлением: «Колени внутрь — разводи по линии носков»;
- пункт шагов/ошибок — до 300 символов, до 20 пунктов; описание — до 2000 символов, описание программы — до 1000.

Обновить снимки источников: `yarn content:sources` (free-exercise-db и wger).

### 3. Проверить локально

```bash
yarn content:import prisma/content/patches/<патч>.json --dry-run   # отчёт «создам / обновлю / ошибки», без записи
yarn content:apply-guides prisma/content/guides.json --dry-run
```

Локальная база может не совпадать с продом: записи, которые есть только на проде, проверка назовёт неизвестными. Окончательная проверка — `--dry-run` на сервере.

### 4. Залить на прод

Патчи и `guides.json` попадают на сервер вместе с кодом (`deploy.sh` → `git pull`). На сервере в `apps/server`:

```bash
tar czf catalog-uploads.tgz uploads/catalog                         # бэкап картинок
yarn content:import prisma/content/patches/<патч>.json --dry-run
yarn content:import prisma/content/patches/<патч>.json
yarn content:apply-guides prisma/content/guides.json --dry-run      # ожидаем «пропущено 0»
yarn content:apply-guides prisma/content/guides.json
```

Патчи — по порядку дат в имени: программы ссылаются на упражнения из более ранних патчей (`2026-10-18-measure.json` раньше нужен для кардио в программах — порядок задаёт список в «Истории» ниже). `guides.json` трогает только существующие записи, его можно до или после патчей.

`apply-guides` пишет только описание, шаги, ошибки и фото финиша; картинки качает до записи в базу. Если запись изменилась после выкачки, она будет в «пропущено» — выкачай заново и переделай её.

### 5. Влить в catalog.json

После успешной заливки:

```bash
yarn content:merge prisma/content/patches/<патч>.json prisma/content/guides.json
yarn content:import prisma/content/catalog.json --dry-run   # catalog.json по-прежнему валиден
```

Коммить `catalog.json` вместе с патчем. Записи без `code` (одобренные черновики) живут только в базе и в `catalog.json` не попадают.

## Скрипты

| Команда | Где | Что делает |
|---|---|---|
| `content:export [файл]` | сервер | снимок справочника прода |
| `content:sources [источник…]` | локально | снимки внешних источников в `sources/` |
| `content:enrich <снимок> [--limit N] [--out папка] [--batch id]` | локально | техника через Claude Batch API → `guides.json` + `review.md` |
| `content:import [файл] [--dry-run] [--no-images]` | оба | импорт патча или `catalog.json` по `code` |
| `content:apply-guides <guides.json> [--dry-run]` | сервер | запись техники по `id` + `updatedAt` |
| `content:merge <файл…>` | локально | влить патч / `guides.json` в `catalog.json` |
| `content:migrate-cardio [--dry-run]` | сервер, разово | старые кардио-блоки комплексов → строка упражнения на время в конце комплекса; нераспознанные — отчётом |
| `content:setup` (`content.sh`) | чистая база | сид мышц и суставов + импорт `catalog.json` |

## История

Порядок заливки на прод: `2026-10-18-measure.json` → `content:migrate-cardio` → `2026-10-17-programs.json` → `guides.json`.

- `patches/2026-10-18-measure.json` — мера упражнений: 9 кардио из free-exercise-db (дорожка: ходьба, трусца, бег; эллипс; велотренажёр и горизонтальный; гребной; степпер; скакалка), кардио — в минутах (`MINUTES`), планка и боковая планка — в секундах (`TIME`). Затем `content:migrate-cardio` переносит старые кардио-блоки комплексов в строки упражнений.
- `patches/2026-10-17-programs.json` — 6 упражнений (кубковые приседания, отжимания с колен и уголком, обратная тяга, выпады без веса, скалолаз), группа тегов «Цель», 10 программ, старые шаблоны кроме «Универсальной» сняты с витрины.
- `guides.json` от 2026-10-17 — описание, шаги и ошибки для 346 записей прода.
