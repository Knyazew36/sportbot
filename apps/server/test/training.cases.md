# Интеграционные тесты: дни плана и тренировки

Тесты гоняют настоящие сервисы (`PlanDayService`, `PollService`, `WorkoutService`, `PauseService`,
`PlanCronService`, `DayService`, `StatsAppService`) на отдельной базе Postgres. Время подменяется
(`setSystemTime`), отправка в мессенджер — заглушка, которая копит сообщения.

Базовый пользователь, если не сказано иное: пояс `Europe/Moscow`, тренировочные дни Пн/Ср/Пт,
утро 08:00, вечер 20:00, онбординг пройден, есть программа из двух комплексов.
Опорная неделя: Пн 12.10.2026 … Вс 18.10.2026.

## Инвариант (проверяется после каждого теста)

- **INV-1.** Нет ни одного `PlanDay` с `status = MISSED` и `date > today` (today — в поясе пользователя).
- **INV-2.** Календарь (`/stats/calendar`) и неделя на «Сегодня» (`/day/today`) не отдают `MISSED`
  ни для одной будущей даты.
- **INV-3.** Будущие дни не влияют на серию: `currentStreak`/`bestStreak` совпадают с пересчётом
  только по дням `date <= today`.

## A. Отображение без действий

| # | Дано | Ожидаем |
|---|------|---------|
| A1 | Новый пользователь, Ср 14.10 10:00, записей нет | Календарь: дни после 14.10 — `FUTURE`; прошлые — `REST` |
| A2 | То же | Неделя: Пт 16.10 — `PLAN`, Сб/Вс — `REST`, Пн/Вт (прошлые, без записи) — `REST` |
| A3 | Сегодня `PENDING` | Календарь: сегодня — `PENDING`, неделя — `PLAN` |

## B. Крон: утро, вечер, просрочка

| # | Дано | Ожидаем |
|---|------|---------|
| B1 | Ср 08:00, тик | Создан `PlanDay` на сегодня, `PENDING`, одно утреннее сообщение |
| B2 | Повторный тик в 08:01 | Новых сообщений нет |
| B3 | Ср `PENDING` без ответа, тик в Чт 12:00 | Ср остаётся `PENDING` (ждём до конца следующего дня) |
| B4 | То же, тик в Пт 00:01 | Ср → `MISSED`; Пт не трогается |
| B5 | Есть `RESCHEDULED` на завтра, тик сегодня | Завтрашний день остаётся `PENDING` |
| B6 | Сервер «простоял» 3 дня, первый тик | В `MISSED` уходят только прошлые дни, будущих записей не появляется |
| B7 | Тик в нетренировочный день (Вт) | `PlanDay` не создаётся |

## C. Ответы пользователя

| # | Дано | Ожидаем |
|---|------|---------|
| C1 | Ср, «сегодня не буду» (`/day/skip`) | Ср → `MISSED`; `missedInRow = 1`; Чт и дальше без записей |
| C2 | После C1 (завтра Чт — не тренировочный) | `canReschedule = true` |
| C3 | Принять перенос | На Чт создан `RESCHEDULED`/`PENDING`; календарь Чт — `FUTURE`, не `MISSED` |
| C4 | Чт: перенесённый день пропущен | Запись Чт удалена, Ср остаётся `MISSED`, второго пропуска нет |
| C5 | Чт: тренировка в перенесённый день | Ср → `DONE` с этой тренировкой, запись Чт удалена |
| C6 | Пт `skip`, завтра Сб — не тренировочный | Пропуск только на Пт |
| C7 | Вечернее «нет» | Сегодня `MISSED`, будущие дни не созданы |
| C8 | Вечернее «да» | Сегодня `DONE`, серия +1 |
| C9 | Три пропуска подряд | `suggestPause = true`, будущие дни не трогаются |

## D. Внеплановая тренировка

| # | Дано | Ожидаем |
|---|------|---------|
| D1 | Пн `MISSED`, тренировка во Вт | Пн → `DONE`, тренировка `unplanned` |
| D2 | Пропусков нет, тренировка во Вт | Закрывается ближайший тренировочный день (Ср) — **уточнить, нужно ли это вообще** |
| D3 | После D2 удалить тренировку Вт | Ср **не** `MISSED`: снова `PENDING` |
| D4 | После D2 наступила Ср, тренировка в Ср | Тренировка Ср — плановая (`unplanned = false`), не «сдвигает» Пт |
| D5 | После D2 в Ср утром тик | Утренний вопрос: либо не задаётся (день уже закрыт), либо задаётся — зафиксировать решение |
| D6 | После D2 статистика недели | Будущий `DONE` не раздувает посещаемость за прошедшие дни |

## E. Удаление и исправление отметок

| # | Дано | Ожидаем |
|---|------|---------|
| E1 | Удалить тренировку, закрывшую сегодняшний (или вчерашний) день | День → `PENDING`, серия пересчитана; пропуск поставит крон после срока ответа |
| E2 | Удалить тренировку дня позавчера и раньше | Тот день → `MISSED` |
| E3 | `fix` будущего дня в `MISSED` | 400, день не меняется |
| E4 | `fix` будущего дня в `DONE` | 400 |
| E5 | `/stats/day` для будущей даты | `fixTo = []` |
| E6 | `fix` дня старше 7 дней | 400 |
| E7 | `fix` DONE → MISSED для простой тренировки | Тренировка удалена; для детальной — осталась в истории без дня |

## F. Пауза

| # | Дано | Ожидаем |
|---|------|---------|
| F1 | Пауза до Вс с Ср | Сегодняшний `PENDING` → `PAUSED`; неделя Пт — `PAUSED` |
| F2 | На паузе тики до конца срока | Нет новых `MISSED`, нет опросов |
| F3 | Пауза снята досрочно (в тот же день) | Сегодня/будущие дни, переведённые в `PAUSED`, снова ждут ответа — **подозрение на баг**: `PAUSED` остаётся навсегда, крон их больше не спрашивает |
| F4 | Пауза при существующем `RESCHEDULED` на завтра | Завтра `PAUSED`, не `MISSED` |
| F5 | Пауза закончилась по сроку | Один вопрос «возвращаемся?», дни после окончания — `PLAN`/`FUTURE` |

## G. Часовой пояс и границы суток

| # | Дано | Ожидаем |
|---|------|---------|
| G1 | Пояс `Asia/Vladivostok`, 23:30 UTC (= 09:30 следующего дня местного) | «Сегодня» — местная дата, утренний вопрос про неё |
| G2 | То же, просрочка | `MISSED` получает только день `< вчера` по местному времени |
| G3 | Пользователь сменил пояс с Владивостока на Москву | Сегодняшний по-старому день стал «завтра»: он не должен стать `MISSED` |
| G4 | Пояс `America/Los_Angeles`, вечер местного | Все отметки по местной дате, не UTC |

## H. Серия и статистика

| # | Дано | Ожидаем |
|---|------|---------|
| H1 | DONE, DONE, MISSED, DONE | current = 1, best = 2 |
| H2 | Будущий `DONE` (после D2) | Не увеличивает текущую серию раньше времени — **уточнить** |
| H3 | Посещаемость недели в середине недели | Знаменатель — только прошедшие/сегодняшние плановые дни |
