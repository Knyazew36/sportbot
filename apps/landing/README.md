# Лендинг Спортбота

Статический сайт без сборки: `index.html`, `styles.css`, `tokens.css` (копия `packages/brand/tokens.css`), `assets/`.
Открыть: из корня репозитория `npx serve apps/landing`, затем http://localhost:3000.
Перед выкатом заменить плейсхолдеры `{BOT_TG}`, `{BOT_MAX}`, `{SUPPORT_CONTACT}`, `{PRIVACY_URL}`, `{TERMS_URL}` и домен `example.com` (см. TODO в `index.html`).
Тексты: `docs/copy.md`, SEO: `docs/seo.md`, бриф: `docs/brief.md`.
Картинки промо пока PNG (до ~560 КБ); для продакшена пережать в webp/avif.
